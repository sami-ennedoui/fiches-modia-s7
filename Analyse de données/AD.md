## ACP et CA côte à côte
|                | ACP                                        | CA                                  |
| -------------- | ------------------------------------------ | ----------------------------------- |
| Données        | $n$ individus, $p$ variables quantitatives | tableau de contingence $I \times J$ |
| Individus      | lignes de $X$                              | profils lignes, et profils colonnes |
| Poids          | $\frac{1}{n}$                              | $f_{i+}$, ou $f_{+j}$               |
| Métrique       | identité ou $D_{1/\sigma^{2}}$             | $W_{Y}^{-1}$, ou $W_{X}^{-1}$       |
| Inertie totale | $\sum_{j} \mathrm{Var}(X^{(j)})$           | $\frac{S_{\chi^{2}}}{n}$            |
| Nombre d'axes  | $p$                                        | $\min(I,J)-1$                       |
