# Développements de Taylor
poly p. 9-10

## Une variable
poly p. 10

Pour $f : \mathbb{R} \to \mathbb{R}$ assez régulière :

| Ordre | Développement | Hypothèse suffisante |
|---|---|---|
| 1 | $f(x+h) = f(x) + f'(x)h + o(h)$ | $f$ dérivable en $x$ |
| 1 | $f(x+h) = f(x) + f'(x)h + O(h^2)$ | $f$ de classe $C^2$ |
| 2 | $f(x+h) = f(x) + f'(x)h + \frac12 f''(x)h^2 + o(h^2)$ | $f$ deux fois dérivable en $x$ |
| 2 | $f(x+h) = f(x) + f'(x)h + \frac12 f''(x)h^2 + O(h^3)$ | $f$ de classe $C^3$ |

Forme générale à l'ordre $n$ :
$$f(x+h) = f(x) + f'(x)h + \dots + \frac{f^{(n)}(x)}{n!}h^n + R.$$

| Reste $R$ | Hypothèse | Nom |
|---|---|---|
| $o(h^n)$ | $f$ est $D^n$ | Peano |
| $O(h^{n+1})$ | $f$ est $C^{n+1}$ | |
| $\frac{f^{(n+1)}(c)}{(n+1)!}h^{n+1}$ avec $x \leq c \leq x+h$ | $f$ est $D^{n+1}$ | valeur moyenne, ou Lagrange |
| $\int_0^h \frac{f^{(n+1)}(x+t)}{n!}(h-t)^n\,dt$ | $f^{(n+1)}$ intégrable | reste intégral |

## Plusieurs variables
poly p. 10

Pour $f : \mathbb{R}^n \to \mathbb{R}^p$ assez régulière :
$$f(x+h) = f(x) + \mathrm{Jac}_x[f]\,h + o(\|h\|).$$

Pour $f : \mathbb{R}^n \to \mathbb{R}$, à savoir par cœur :
$$f(x+h) = f(x) + \langle \nabla f(x), h\rangle + o(\|h\|),$$
$$f(x+h) = f(x) + \langle \nabla f(x), h\rangle + \frac12 \langle H[f](x)h, h\rangle + o(\|h\|^2).$$
- La première vaut dès que $f$ est différentiable en $x$, la seconde dès que $f$ est deux fois différentiable en $x$, par exemple $C^2$.
- Pour se ramener à une variable, on pose $\varphi(t) = f(x+td)$. Alors $\varphi'(t) = \langle \nabla f(x+td), d\rangle$ et $\varphi''(t) = \langle H[f](x+td)d, d\rangle$.
- Ces développements servent dans [1.8 - Prouver la convexité](1.8%20-%20Prouver%20la%20convexit%C3%A9.md), [4.1 - Second ordre sur un ouvert](../4%20-%20Conditions%20du%20second%20ordre/4.1%20-%20Second%20ordre%20sur%20un%20ouvert.md) et [6.1 - Gradient Lipschitz et lemme de descente](../6%20-%20M%C3%A9thodes%20de%20descente%20du%20premier%20ordre/6.1%20-%20Gradient%20Lipschitz%20et%20lemme%20de%20descente.md).

## À retenir
- Ordre 2 : $f(x+h) = f(x) + \langle \nabla f(x), h\rangle + \frac12\langle H[f](x)h,h\rangle + o(\|h\|^2)$.
- Le petit $o$ demande la régularité au point, le grand $O$ une dérivée d'ordre supérieur bornée.
